# Vue Engineering Gauntlet

A project-based frontend engineering training system for learning Vue through real-world challenges, debugging, architecture decisions, testing, and independent problem solving.

This is not a tutorial course.

The goal is not to memorize Vue syntax.

The goal is to become capable of independently building production-grade frontend systems.

---

# Philosophy

Most courses teach developers how to follow along.

This platform trains developers to:
- think independently
- research documentation
- debug systems
- structure applications
- make engineering decisions
- ship working software

Learners are intentionally exposed to ambiguity, constraints, edge cases, and real engineering problems.

---

# How It Works

Each project follows the same cycle:

1. Learn a small set of core concepts
2. Research missing knowledge independently
3. Build the project
4. Pass automated tests
5. Receive engineering feedback
6. Compare with reference solutions
7. Reflect and improve

---

# What Makes This Different

Unlike traditional tutorials, this platform emphasizes:

- deliberate practice
- documentation literacy
- debugging skills
- architecture thinking
- production constraints
- progressive difficulty
- self-directed problem solving

# Features

## 20 Progressive Vue Projects

Projects gradually increase in complexity and realism.

Topics include:
- reactivity
- component architecture
- composables
- routing
- async state
- caching
- SSR
- testing
- performance
- accessibility
- debugging
- TypeScript

---

## Automated Testing

Projects are validated using:
- Vitest
- Vue Testing Library
- Playwright

Learners receive immediate feedback on:
- functionality
- edge cases
- accessibility
- async behavior
- stability

---

## Progressive Hint System

Hints are layered to preserve productive struggle.

- Level 1 → Directional clue
- Level 2 → Relevant concept
- Level 3 → Pseudo-code guidance
- Level 4 → Partial implementation

---

## AI Engineering Review

Submissions can be reviewed for:
- architecture quality
- maintainability
- composable usage
- readability
- code smells
- Vue anti-patterns

The focus is feedback, not arbitrary scores.

---

## Reference Solutions

After completion, learners unlock:
- full implementations
- architectural reasoning
- performance considerations
- tradeoff explanations
- common mistakes

---

## Debugging Challenges

Some projects intentionally include:
- memory leaks
- stale state
- race conditions
- hydration issues
- infinite reactive loops
- broken tests

Because real engineering includes debugging.
